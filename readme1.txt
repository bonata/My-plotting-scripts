README

This repository contains source data for the main figures and partial scripts used in the study:

“Elevated temperature simulating heatwaves restructures active methanotrophs in permafrost soils”

Contents may include:

* Source data for main figures
* Partial plotting and analysis scripts
* Comparative genomic analysis files
* Metagenomic mapping results
* Supplementary tables and metadata

Additional plotting scripts are available on GitHub:
https://github.com/bonata/My-plotting-scripts.git

Raw 16S rRNA gene amplicon, pmoA gene amplicon, metagenomic, and MAG sequences are available in the NCBI Sequence Read Archive (SRA) under BioProjects:
PRJNA507032
PRJNA507039
PRJNA1306690

Metatranscriptomic datasets are available in MG-RAST under the study name:
Wetlands_MetaT
